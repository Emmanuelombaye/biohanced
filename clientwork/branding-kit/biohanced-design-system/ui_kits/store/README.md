# Store UI kit — Biohanced Labs

A high-fidelity recreation of the Biohanced Labs storefront homepage, the brand's primary surface.

`index.html` is a self-contained static recreation (nav → hero → trust strip → category grid → featured products → footer) linking the real `styles.css` tokens and the exported product/logo assets. It doubles as a Starting Point.

Source of truth: `Biohanced Labs Store.dc.html` in the parent project — a full interactive storefront (home, catalog, product detail, cart, checkout, COA, FAQ). This kit reproduces the homepage look; extend it by lifting sections from that DC.

Screens worth adding next: product detail (variant tier pricing, COA link, highlights), catalog with category filter, cart/checkout.
