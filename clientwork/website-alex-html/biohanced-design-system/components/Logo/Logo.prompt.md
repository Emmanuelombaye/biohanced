The Biohanced Labs logo. The mark is a gradient tile with a knockout bolt; the wordmark is Archivo 900 BIOHANCED over spaced Space Grotesk LABS.

```jsx
<Logo variant="horizontal" size={34} onDark />   {/* nav */}
<Logo variant="stacked" size={92} onDark={false} /> {/* light lockup */}
<Logo variant="mark" size={120} />               {/* app icon */}
```

Prefer the exported PNGs in `assets/logos/` for pixel-final placement; use this component for live/responsive lockups. Never recolor the bolt gradient outside the approved colorways.
